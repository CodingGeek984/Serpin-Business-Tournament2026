# Serpin Business Tournament 2026 🚀

Добро пожаловать в репозиторий проекта **Serpin Business Tournament 2026** — инновационной B2B платформы для управления бизнесом, маркетингом и лояльностью клиентов.

## 🌟 О проекте

Serpin Business Tournament — это не просто CRM, это система, превращающая рутину управления бизнесом в увлекательный процесс с элементами геймификации. Платформа помогает владельцам малого и среднего бизнеса удерживать клиентов, запускать умные маркетинговые акции и принимать решения на основе данных с помощью встроенного ИИ-ассистента.

**Ключевые фичи:**
- **Геймификация:** Уровни, баллы (XP) для владельцев бизнеса за активное ведение дел.
- **Мастер Акций (Promo Wizard):** Быстрое создание акций (скидки, штампы, счастливые часы) с генерацией креативов через ИИ.
- **Умная Аналитика:** Дашборд с ИИ-советами по увеличению выручки на основе ваших реальных продаж.
- **ИИ-Ассистент:** Встроенный чат с бизнес-ассистентом (на базе Google Gemini), который может создавать акции и управлять базой клиентов прямо из чата.
- **Центр Уведомлений:** Умная сортировка критически важных событий (Alerts) и системных уведомлений.

## ⚙️ Как это работает

Проект состоит из двух основных частей: **Frontend** (пользовательский интерфейс) и **Backend** (серверная логика и база данных). Они обмениваются данными через REST API (JSON). 
Аутентификация построена на токенах (JWT), а безопасность обеспечивается строгими настройками CORS.

### 🐍 Как работает Backend
Бэкенд написан на языке **Python** с использованием легковесного и быстрого микрофреймворка **Flask**.

- **Роутинг:** Архитектура разбита на маршруты (`routes.py`), обрабатывающие бизнес-логику (пользователи, акции, клиенты, уведомления).
- **Безопасность:** Используется `flask_jwt_extended` для генерации и проверки токенов (JWT) при каждом запросе. Есть встроенный механизм блокировки (revoked) старых токенов.
- **CORS:** Настроен на прием запросов только с доверенных источников (локально это `http://localhost:5173`).
- **Запуск:** Сервер поднимается локально на порту `5001`.

### ⚛️ Как работает Frontend
Фронтенд представляет собой Single Page Application (SPA), написанное на **React** и собранное с помощью **Vite**.

- **Стилизация:** Используется **TailwindCSS** для быстрой и гибкой верстки, а также библиотека компонентов `lucide-react` для красивых иконок.
- **Анимации:** За плавные переходы, всплывающие окна и интерфейс отвечает `framer-motion`.
- **Состояние и Контекст:** Используется мощная система React Context:
  - `UserContext` — данные бизнеса, акции, статистика.
  - `AIContext` — интеграция с Google Gemini API для чата и автоматической генерации акций.
  - `NotificationContext` — система SSE (Server-Sent Events) и умных push-уведомлений.

## 🎯 Как пользоваться проектом

1. **Регистрация / Вход:** После входа в систему вы попадаете на главный Дашборд.
2. **Дашборд:** Здесь вы видите сводку по выручке и клиентам. Нажмите на кнопку "Обновить" в блоке **AI Советы**, чтобы ИИ проанализировал ваши цифры и дал персональные рекомендации.
3. **Акции:** Перейдите во вкладку "Акции" и нажмите "Создать акцию". Вы можете выбрать ручной шаблон или нажать "Доверьте создание ИИ", описав свою идею (например: "Акция для студентов утром").
4. **ИИ-Ассистент:** Откройте чат с ассистентом. Вы можете спрашивать его о маркетинге, просить проанализировать продажи или даже сказать "Создай акцию на кофе", и он выполнит это действие за вас.

## 🚀 Как запустить проект локально

Вам потребуется установленный [Python 3.9+](https://www.python.org/) и [Node.js (18+)](https://nodejs.org/).

### 1. Клонирование репозитория
```bash
git clone https://github.com/CodingGeek984/Serpin-Business-Tournament2026.git
cd Serpin-Business-Tournament2026
```

### 2. Запуск Backend (Flask)
```bash
cd backend

# (Рекомендуется) Создать виртуальное окружение
python -m venv venv
source venv/bin/activate  # Для Windows: venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt

# Настройка переменных окружения
# Скопируйте .env.example в .env и заполните необходимые ключи (JWT_SECRET_KEY и т.д.)

# Запуск сервера (запустится на порту 5001)
python app/app.py
```

### 3. Запуск Frontend (React/Vite)
Откройте новый терминал и перейдите в папку frontend:
```bash
cd frontend

# Установка зависимостей
npm install

# Настройка переменных окружения
# Убедитесь, что в файле frontend/.env указаны необходимые API ключи (например, VITE_GEMINI_API_KEY)

# Запуск сервера разработки (запустится на порту 5173)
npm run dev
```

### 4. Использование
Откройте в браузере ссылку `http://localhost:5173`. Frontend автоматически подключится к Backend, который работает на `http://localhost:5001`.
